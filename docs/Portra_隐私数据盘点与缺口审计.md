# Portra 隐私数据盘点与缺口审计

> 审计日期：2026-10-28  
> 审计分支：`feature/harmony-c-ui-polish`  
> 状态：第一轮代码证据盘点，待产品负责人审核  
> 性质：用于后续起草隐私政策和制定整改计划，不替代正式法律意见

## 1. 审计范围

本轮以计划发布到华为应用市场的 HarmonyOS App 为主，覆盖：

- `harmony/`：鸿蒙客户端、启动流程、登录会话、本地存储和权限声明。
- `backend/`：账号、短信登录、身份切换、个人主页、社交关系、内容、消息、订单、文件、认证、审核及 AI 企划。
- `frontend/`：作为同一服务的 Web 补充客户端，单独标记其本地缓存和 IP 定位行为；Web 特有行为不应自动写成鸿蒙客户端行为。
- `scripts/moma_*`：移动云 MoMA 安全桥和真实调用脚本。

本轮未能仅凭仓库确认生产运营主体、服务器/数据库/文件存储供应商、部署地域、备份周期、日志平台及客服联系方式。这些项目必须由负责人补充。

## 2. 结论摘要

代码中已经存在较好的手机号加密、会话令牌保护和私有文件访问控制，但当前还不具备可以直接通过隐私合规审核的完整闭环。

最重要的事实是：

1. 仓库内没有隐私同意 UI、同意版本、同意时间或撤回记录。
2. 鸿蒙 App 在首屏出现前就创建持久化设备安装 ID，页面出现后立即尝试恢复登录会话。
3. 登录和业务数据请求没有受隐私同意状态统一约束。
4. 已新增账号注销申请、状态查询、管理员审核、会话撤销和核心资料匿名化流程；文件对象、备份及到期历史数据仍需部署周期清理任务。
5. 后端会把用户 IP 发给 `ip-api.com` 获取省级位置，当前使用明文 HTTP；Web 端还可能直接调用高德 IP 定位或 `ip-api.com`。
6. AI 企划会把用户填写的主题、城市、地点、时间、预算和自由文本偏好发送到移动云 MoMA。
7. 真实认证材料、交付照片、争议证据等属于高敏感数据，但保存期限和到期删除机制未定义。
8. 客片展示授权有“同意/拒绝/到期”模型，但没有用户主动撤回授权的接口。

## 3. 个人信息处理清单

### 3.1 账号与短信登录

处理的信息：

- 手机号原文：仅在短信发送和登录验证流程中短时使用。
- 手机号密文、手机号 HMAC 哈希、脱敏手机号。
- 短信验证码哈希、用途、过期时间、尝试次数、消费时间。
- 短信请求 IP、设备安装 ID、短信服务商消息 ID、发送状态和时间。
- 登录时间、账号状态、用户 ID、当前身份及身份绑定记录。

目的：注册/登录、账号唯一识别、短信风控、验证码防滥用、会话管理和身份切换。

存储与安全措施：

- 用户手机号不以明文落库；数据库保存 AES-GCM 加密值、HMAC-SHA256 查询值和脱敏展示值。
- 短信验证码以哈希保存，默认 5 分钟过期，最多尝试 5 次。
- 生产环境通过阿里云短信发送手机号和验证码模板参数。

当前问题：

- 虽然 Repository 声明了删除过期短信挑战的方法，但未发现实际定时清理任务。
- `dev`/`smoke` 环境会把脱敏手机号和明文验证码写入日志；不得用于真实用户环境。
- 获取验证码前没有隐私政策确认。

### 3.2 设备标识与登录会话

处理的信息：

- 随机生成的设备安装 UUID。
- 会话 ID、用户 ID、设备 ID、可选设备名称。
- 访问令牌、刷新令牌哈希、创建时间、过期时间、最后活跃时间、撤销时间和原因。

目的：识别安装实例、限制短信滥用、保持登录、刷新令牌和撤销会话。

存储与安全措施：

- 鸿蒙刷新令牌保存在加密 Asset Store，设置为不跨设备同步。
- 鸿蒙访问令牌只保存在内存。
- 服务端只保存刷新令牌哈希，默认刷新会话有效期 30 天。

当前问题：

- `EntryAbility.onCreate()` 在隐私确认前调用 `DeviceIdentityStore.getOrCreate()` 并持久化安装 UUID。
- `Index.aboutToAppear()` 在隐私确认前调用 `restoreSession()`，可能向服务端发送刷新令牌。
- `backup_config.json` 允许备份恢复，但未明确排除安装 ID 等偏好数据，需要真机验证和收紧配置。
- 未发现用户查看、撤销其他设备会话的客户端入口。

### 3.3 基础资料与双身份资料

- 性别、生日、地区展示文案、城市代码及相应可见性开关。

- 已提供账号注销申请及审核完成后的资料匿名化能力；个人信息副本导出和分项删除能力仍待实现。

处理的信息：

- 动态点赞/收藏用户 ID。
- 用户对服务橱窗的意向关系和创建时间。

### 3.7 会话、消息和报价

处理的信息：

- 会话双方、来源需求/橱窗/订单和最后消息时间。
- 消息正文、附件、消息类型、引用对象、已读状态和发送时间。
- 报价金额、拍摄时间、地点、服务内容、交付数量、照片使用范围、合同条款、安全提示版本和备注。

目的：约拍沟通、报价确认、订单生成、服务履约和争议追溯。

存储与访问：消息附件属于私有文件，仅会话参与者、上传者或管理员可访问。

当前问题：

- 用户删除会话只是对本人隐藏，不会删除消息原文。
- 未定义消息和报价的服务端保存期限。
- Web 客户端会把会话和本地消息正文写入浏览器 `localStorage`，默认缓存 7 天；退出登录不会统一清除这些业务缓存。

### 3.8 订单、支付、交付与客片授权

处理的信息：

- 订单双方、报价/会话/需求/橱窗关联、金额、平台费用、摄影师收入。
- 拍摄起止时间、拍摄地点、交付期限、合同条款、安全提示确认和状态日志。
- 模拟支付编号、第三方交易号、付款和退款金额及时间。
- 交付照片/压缩包、文件名、类型、大小、上传时间、交付备注。
- 客片展示授权范围、状态、备注、授权时间、到期时间及获授权文件。

目的：交易履约、资金状态、照片交付、纠纷处理和经客户授权后的作品展示。

安全措施：

- 交付、客片授权、消息附件、评价证据和认证文件默认是私有文件。
- 交付文件只允许订单参与者访问。
- 只有状态为 `GRANTED`、范围为作品集展示且未过期的授权文件才允许公开访问。

当前问题：

- 客户只能同意或拒绝，未发现主动撤回已同意授权的接口。
- 订单和交付文件没有保存期限或订单结束后的删除规则。
- 当前支付为模拟支付，正式接入支付机构后必须重新盘点共享字段。

### 3.9 评价、投诉、举报和争议处理

处理的信息：

- 评分、评价正文、回复、评价双方和可见状态。
- 投诉理由、证据文件、被投诉人、仲裁结果和管理员意见。
- 订单争议理由、回复内容、责任认定、退款金额和管理员意见。
- 内容/用户举报对象、理由、描述、处理状态和处理记录。
- 管理员审核行为和审计记录。

目的：内容治理、纠纷仲裁、信用计算、投诉处理和管理员问责。

当前问题：证据材料和管理员处理记录可能需要更长保存期，但仓库没有明确区分普通业务数据和争议证据的保存期限。

### 3.10 信用、通知和推荐

处理的信息：

- 信用分、信用变动、关联订单、变动原因、履约和评价聚合指标。
- 通知标题、正文、触发用户、关联对象、已读状态和元数据。
- 需求、摄影师、地理/预算/风格匹配所需字段。

目的：信用展示、风险控制、业务提醒和个性化匹配。

当前问题：

- 信用摘要对所有已登录用户开放，但缺少显式公开说明和关闭机制。
- 如后续把推荐升级为个性化推荐，需要在隐私政策中说明并提供关闭或非个性化选项。

### 3.11 IP 位置推断

处理的信息：用户公网 IP、推断出的省级地区或城市代码。

处理路径：

- 后端旧式学号密码登录会把客户端 IP 请求发送至 `http://ip-api.com/json/{ip}`，并把返回省份写入用户 `cityCode`。
- Web 个人主页会优先调用高德 IP 定位；未配置高德 Key 时调用 `http://ip-api.com/json/`，并把结果在浏览器缓存 24 小时。
- 当前 HarmonyOS 手机验证码登录流程未直接调用 `IpLocationService`，但共享后端仍保留上述行为。

当前问题：

- `ip-api.com` 请求使用 HTTP，存在传输保护不足。
- 自动 IP 定位缺少显式告知、选择和第三方共享说明。
- 旧式学号密码接口虽然 Controller 已停用，但服务代码仍保留相关逻辑。

### 3.12 AI 约拍企划

处理的信息：拍摄主题、城市、地点偏好、时间偏好、预算范围、其他自由文本偏好，以及模型生成结果。

处理路径：

`HarmonyOS App -> Portra 后端 -> localhost 安全桥 -> 移动云 MoMA 官方 AITC SDK -> MoMA 模型服务`

目的：生成可编辑的约拍创意、场景、服装道具、镜头和安全建议。

安全措施：

- API Key 只通过本机安全桥环境变量注入，不进入客户端或 Java 后端。
- 官方 SDK 使用远程证明和加密推理。
- 系统提示要求模型不索取身份证、电话或精确住址。

当前问题：

- 自由文本仍可能被用户主动填入敏感信息，不能仅依赖提示词。
- 需要明确移动云服务提供方、处理目的、字段范围、保存期限和隐私政策链接。
- 生成按钮附近应提供简短 AI 数据处理提示；必要时取得单独确认。

## 4. 客户端本地存储清单

### 4.1 HarmonyOS App

- 安装 UUID：Preferences 持久化；当前在首次隐私确认前创建。
- 刷新令牌：加密 Asset Store，`SYNC_TYPE.NEVER`。
- 访问令牌：内存，不持久化。
- 动态列表：内存短期缓存，按会话版本隔离。
- 备份：应用配置当前允许备份恢复，具体纳入范围尚未验证。

### 4.2 Web 补充客户端

- `portra-device-id`：浏览器安装 ID，长期保存在 `localStorage`。
- `camera-p4-user-profiles`：昵称、简介、城市、双身份展示资料等，长期保存在 `localStorage`。
- 需求和服务橱窗草稿：地点、描述、预算、日期和文件引用等，长期保存在 `localStorage`，未见自动过期。
- 会话和本地消息：正文及参与者等信息，`localStorage` 缓存 7 天。
- 会话已读状态：`localStorage`，未见自动过期。
- 订单/交付/授权等工作流快照：`sessionStorage`，随浏览器会话保存。
- IP 定位结果：`localStorage` 缓存 24 小时。
- 当前退出登录只清理内存会话/服务端会话，不统一清除上述资料和业务缓存。

## 5. 已确认的外部接收方

### 阿里云 ECS 基础设施

- 当前已知环境：临时 Staging，地址 `47.76.106.57`，仓库文档标注为中国香港地域的阿里云 ECS；该地址尚不能被视为已确定的正式 Production 地址。
- 云服务主体：阿里云计算有限公司，最终以实际购买协议和账号账单为准。
- 数据库：Staging 启动门禁强制使用 `jdbc:mysql://127.0.0.1:3306/portra_staging`，可确认当前设计为 ECS 内自建 MySQL，而非远程 RDS。
- 文件：后端只有 `LocalFileStorage` 实现，Staging 默认目录为 `/opt/portra/uploads`，可确认当前设计为 ECS 本地文件系统，而非 OSS。
- 备份：实际备份介质、周期和地域仍待服务器侧核实。
- 决策：负责人已确认正式版本继续使用中国香港服务器。中国香港地域不应写成“境内存储”；上线前必须完成个人信息出境影响评估、单独同意及其他适用的出境合规程序。

### 阿里云短信

- 数据：手机号、短信签名/模板和验证码模板参数。

## 6. 现有保护措施

- 手机号采用加密、哈希和脱敏三层存储，不以明文作为数据库登录标识。
- 短信验证码采用哈希、过期时间、尝试次数及 IP/设备频率限制。
- 服务端刷新令牌只保存哈希；鸿蒙刷新令牌进入加密 Asset Store。
- 生产配置要求外部密钥并禁止使用开发/冒烟环境配置。
- 文件按公开/私有业务类型分类，交付、认证、消息附件和证据默认私有。
- 私有文件下载会校验上传者、订单参与者、会话参与者、管理员或有效客片授权。
- 当前鸿蒙安装包只声明 `ohos.permission.INTERNET`，尚未声明相机、相册、定位或麦克风权限。
- 客片文件只有在明确授权、用途匹配且未过期时才可公开。
