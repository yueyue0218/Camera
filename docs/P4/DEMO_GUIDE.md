# Portra 约拍平台 — 本地运行与演示说明

> **适用对象：** 验收助教、评审人员  
> **对应分支：** `main`  
> **最后更新：** 2026-06-07

---

## 一、环境要求

| 依赖 | 要求 | 说明 |
|---|---|---|
| Java | 17 | `java -version` 确认 |
| Maven | 3.8+ | 已内置 `mvnw` 可免装 |
| Node.js | 18+ | `node -v` 确认 |
| MySQL | 8.0 | 需提前启动服务，建好数据库 |

---

## 二、数据库初始化

启动 MySQL 后执行：

```sql
CREATE DATABASE IF NOT EXISTS camera_app
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

建表脚本在 `backend/src/main/resources/db/V1_baseline.sql`，项目启动时 **不会自动执行**，需手动运行一次：

```bash
mysql -u root -p camera_app < backend/src/main/resources/db/V1_baseline.sql
```

> 如果已经建过表（非首次），跳过此步。

---

## 三、启动后端

```bash
cd backend
mvn spring-boot:run
```

看到以下日志说明启动成功（约 15 秒）：

```
Started CameraApplication in xx.xxx seconds
```

后端运行在 `http://localhost:8080`。

**邮件配置说明：** 后端已内置 QQ SMTP 配置（`smtp.qq.com:587`），注册时验证码直接查收即可，无需任何额外配置。
---

## 四、启动前端

新开一个终端：

```bash
cd frontend
npm install
npm run dev
```

看到以下日志说明启动成功：

```
Local:   http://localhost:5173/
```

浏览器打开 `http://localhost:5173`。

## 五、注册演示账号

演示需要两个账号：**消费者（单主）** 和 **摄影师**，使用你自己的邮箱注册即可。

### 5.1 注册消费者账号

1. 打开 `http://localhost:5173/login/register`
2. 填写**学校邮箱**（任意可收邮件的邮箱均可），点击"获取验证码"
3. 查收邮件（留意垃圾邮件文件夹），填入 6 位验证码
4. 设置昵称和密码，完成注册

### 5.2 注册摄影师账号

1. 换一个邮箱，重复上述注册流程（注册进来默认也是消费者）
2. 登录后进入**个人主页**（右上角头像 → 我的主页）
3. 点击"**切换到摄影师账号**"按钮，身份切换为摄影师
4. 填写摄影师昵称、简介，点击保存（此步骤会在数据库中初始化摄影师档案）
5. 发布至少一个**服务橱窗**（摄影师主页 → 我的橱窗 → 新增橱窗）

## 六、核心演示路径

### 路径一：完整约拍业务闭环

以下步骤模拟一次完整的约拍订单流程：

| 步骤 | 操作账号 | 操作 | 预期结果 |
|---|---|---|---|
| 1 | 消费者 | 首页 → 服务大厅 → 找到摄影师橱窗 → 点击"发起咨询" | 进入消息会话页 |
| 2 | 摄影师 | 消息页收到新会话 → 发送正式**报价** | 报价卡片出现在会话中 |
| 3 | 消费者 | 查看报价 → 点击"**确认报价**" | 生成订单，跳转订单详情 |
| 4 | 消费者 | 订单详情 → 点击"**模拟支付**" | 订单状态变为 PAID_PENDING_SHOOT |
| 5 | 摄影师 | 订单详情 → 上传**交付文件**（任意图片） | 订单自动推进至 DELIVERED_PENDING_CONFIRM |
| 6 | 消费者 | 订单详情 → 点击"**确认收货**" | 订单状态变为 COMPLETED |
| 7 | 消费者 | 订单详情 → 提交**评价**（给摄影师打分） | 评价成功，摄影师信用分更新 |
| 8 | 摄影师 | 订单详情 → 提交**反向评价**（给消费者打分） | 双向评价完成 |

### 路径二：需求大厅流程

| 步骤 | 操作账号 | 操作 | 预期结果 |
|---|---|---|---|
| 1 | 消费者 | 需求大厅 → 发布拍摄需求（填写城市/日期/预算） | 需求出现在大厅列表 |
| 2 | 摄影师 | 需求大厅 → 找到该需求 → 提交响应 | 响应出现在消费者需求详情页 |
| 3 | 消费者 | 需求详情 → 查看响应列表 → 接受某个响应 | 自动进入会话，后续同路径一步骤 2 起 |

| 模块 | 入口 | 说明 |
|---|---|---|
| 服务大厅 | 首页 → 服务大厅 | 浏览摄影师橱窗，支持城市/风格/价格筛选 |

## 八、常见问题

**Q：注册时收不到验证码？**  
A：检查垃圾邮件文件夹；确认后端已启动且日志无报错。

**Q：切换摄影师身份后页面报错？**  
A：切换后需在个人主页保存一次摄影师资料，系统会自动初始化摄影师档案。

**Q：8080 端口被占用？**  
A：执行 `netstat -ano | findstr :8080` 找到 PID，再 `taskkill /PID <pid> /F` 结束占用进程，然后重启后端。

**Q：数据库连接失败？**  
A：确认 MySQL 服务已启动；默认连接配置为 `root / root`（无密码或空密码），如需修改请编辑 `backend/src/main/resources/application.yml` 中 `spring.datasource.password`。
