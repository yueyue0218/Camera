# Portra 账号注销处理规则

版本：1.0  
更新日期：2026-10-29  
适用范围：Portra HarmonyOS 客户端及其服务端账号体系

## 一、处理流程

1. 用户在“个人主页—设置与隐私—账号与安全—注销账号”提交申请，可填写注销原因。
2. 系统保存申请并向用户展示“待处理、处理中、已拒绝或已完成”的实际状态；重复提交待处理申请不会创建多条记录。
3. 管理员必须填写处理说明。待处理申请仅可进入“处理中、已拒绝或已完成”，处理中申请仅可进入“已拒绝或已完成”。所有处理动作写入管理员审计记录。
4. 账号存在进行中订单或未解决争议时，系统禁止完成注销。管理员账号必须先移除管理权限，且不能注销当前正在操作的管理员账号。
5. 审核通过后，系统在同一数据库事务中完成会话撤销、公开内容下架、关系数据清理和账号匿名化；任何一步失败均回滚，不产生“只删除一半”的状态。

## 二、审核通过后立即处理的数据

- 撤销该账号所有未撤销会话，清除会话中的设备标识和设备名称，使现有访问令牌无法继续访问受保护接口。
- 删除该手机号对应的短信验证码挑战记录。
- 清除学号、密码摘要、手机号密文及索引、手机号掩码、学校、头像、性别、生日、地区、城市和个人简介。
- 将昵称替换为仅含内部用户编号的“已注销用户-编号”，账号状态改为 `DELETED`。
- 删除实名和学生认证记录；认证文件的实际对象存储删除仍须由文件生命周期任务按隐私政策期限完成。
- 关闭并隐藏用户发布的需求，下线并隐藏摄影服务，软删除公开动态。
- 删除关注关系、服务收藏、动态点赞和收藏、会话隐藏偏好及面向该用户的通知；其他用户通知中的操作者标识置空。
- 清空摄影师公开资料和接单状态，删除角色绑定。
- 自动撤回该用户作为客户或摄影师参与的已授权客片公开展示，状态改为 `REVOKED`。

## 三、不会在注销时直接删除的数据

以下数据可能用于履行合同、退款、对账、争议处理、监管配合或保护交易双方权益，注销时保留其业务记录，但只能关联已匿名化的内部用户编号：

- 已完成、已取消或已退款订单及订单状态记录；
- 报价、支付、退款、合同或订单快照；
- 订单关联消息、交付和客片授权/撤回记录；
- 投诉、举报、评价、信用、争议、管理员审核和必要安全日志。

上述数据按《Portra 隐私政策》约定的期限保存：订单、交易、订单关联消息及争议材料原则上保存 3 年，网络安全日志保存 6 个月；期限届满后删除或进一步匿名化。法律法规或正在处理的争议要求继续保存的，仅在必要范围内延长。

## 四、当前尚需部署的配套任务

- 证件原图审核结束后 30 天删除；
- 交付照片在订单完成后 90 天删除；
- 非订单普通聊天、软删除动态和公开内容按约定期限物理清理；
- 文件对象、缓存和备份在最长 30 天滚动周期内覆盖；
- 到期订单、争议和安全日志的删除或匿名化任务。

本阶段已经实现在线账号停用与业务库匿名化，但以上按期执行的文件和历史数据清理任务仍是正式上线前的独立发布门槛，不得仅凭账号状态变更宣称所有数据已物理删除。
