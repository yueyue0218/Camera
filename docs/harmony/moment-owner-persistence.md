# 动态编辑、删除与编号修复（2026-11-02）

开发基线：`feature/harmony-c-ui-polish`，`57e4c8a`。在独立工作区实现，保留个人页和消息页最新改动；不修改 main，不启动模拟器。

## 已确认的问题

- 编辑与删除本来已使用后端 PUT/DELETE。鸿蒙控制器把所有写入错误都转成“结果未确认”，导致参数拒绝、权限拒绝、上传过大等确定失败也被锁住，并隐藏错误码。现在明确拒绝时保留表单并显示安全错误及 HTTP/业务错误码；超时、断网、5xx、解析异常和凭据恢复后未重试仍须核实，不自动重发。
- 后端先清空原相册，再解析缺省图片，文字编辑未携带图片时会丢掉原相册；缺省 mentions 也会清空。独立请求测试在修复前确认原两张变为零张。现在先解析再移除旧图片：省略/null 保留，显式空数组清空，非空数组替换。保留删除旧图片后的 flush，避免现有图片排序唯一约束冲突。
- 写入完成只清动态缓存，没有发送现有个人页监听的内容更新事件。现在同一身份下发布、编辑、删除和结果核实会通知相关页面重新读取；通知订阅者异常不会将已完成写入误判为失败。
- 移除鸿蒙动态卡片及 Web 动态列表、详情的 No. 编号。内部 ID 继续用于 API 和无障碍定位。
